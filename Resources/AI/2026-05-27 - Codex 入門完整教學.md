# 📎 Codex 入門完整教學

## 摘要

> 這篇文章以入門教學形式介紹 Codex 桌面版，涵蓋安裝、介面、設定、Skills、Plugins、網頁開發與 App 開發流程。原文也補充 Mac 與 Windows 之間的功能差異，提醒使用者依平台能力調整期待。

## 重點

- Codex 可管理對話與專案，專案綁定本地資料夾。
- 複雜任務建議先開計畫模式，確認方案後再實作。
- AGENTS.md 與記憶功能可作為長期使用的行為約束。
- Skills 與 Plugins 是擴充 Codex 工作流的核心入口。
- Mac 版目前支援更多 Computer Use 與螢幕上下文能力。

## 可行動事項

- [ ] 建立一個 Codex 專案，先用計畫模式規劃簡單功能頁，再實作並用內建瀏覽器批注修改。

## 原文整理

原文是一篇 Codex 速成教學，作者指出 Codex 在近期快速更新後，已經和幾個月前的版本有明顯差異，因此重新整理一篇更完整的操作指南。文章用一個網頁和一個 App 的實作案例串起整體流程。

### 一、安裝 Codex

作者建議先準備 ChatGPT 帳號，接著到 Codex 官網下載桌面版。Mac 與 Windows 都有安裝版本。登入後，Codex 的使用額度會和 ChatGPT 會員方案相關，也可依需求使用 API key。

安裝流程中，Codex 可從 Claude Code 和 Cowork 匯入既有設定，讓使用者繼承原本的配置與工作習慣。

### 二、認識介面

Codex 介面中間是對話區，左側用來管理對話與專案。原文將兩者區分為：

- 對話：適合調研、規劃等不綁定特定資料夾的小任務。
- 專案：綁定本地資料夾，是開發任務的主要工作區。

同一個專案可開多條對話，每條對話是獨立任務線，但共享同一個專案資料夾。作者建議不要把所有事情塞在同一條對話中，避免上下文越來越長而造成污染。

Codex 也提供權限選擇。保守模式會要求更多審批；自動審查適合日常開發，遇到高風險操作會攔截；完全訪問權限則讓 Codex 自行執行更多操作。模型與推理等級可依任務難度調整，日常可用較高推理等級，複雜工作再提高。

### 三、修改設定

原文建議先調整設定再開始大量使用。常規設定可開啟必要選項，跟進行為可改成「引導」，讓使用者在任務中途插入修改意見，而不必等整個任務結束。

AGENTS.md 被作者視為 Codex 的分層約束系統。全域規則可在個性化設定中設置，作為所有新對話都能繼承的通用行為準則。作者引用的方向包含：

- 實作前先說明假設與不確定性。
- 優先簡單方案，避免不必要抽象。
- 修改要精準，只動與任務直接相關的內容。
- 把任務轉成可驗證目標，完成後檢查。

作者也建議開啟記憶相關功能，讓 Codex 能把對話摘要成記憶片段，之後在相關場景自動取用。

### 四、Skills 與 Plugins

Codex 的 Plugins tab 可切換插件與技能。Skills 是 Agent 可使用的技能檔；Plugins 則是把多個技能、工具和配置打包後的安裝包。Codex 提供可視化管理介面，也內建 Skill creator 與 Plugin creator，可用自然語言描述要建立的技能或插件。

若要下載官方以外的 skill 或 plugin，可直接提供連結讓 Codex 處理。

### 五、開發一個網頁

作者示範建立專案後，先開啟計畫模式，請 Codex 製作一個功能介紹網頁。計畫模式會先釐清需求並提出方案，使用者確認後再實作。

完成後可用 Codex 內建瀏覽器預覽。預覽介面支援截圖與批注；批注功能可以直接圈選頁面元素並寫修改意見，也可調整字體、字號、顏色等參數後再送回 Codex 修改。

若要讓別人看到本地網頁，仍需部署到伺服器。作者提到可透過自製 Skill 協助公司內部部署，但具體部署方式需依環境決定。

### 六、開發一個 App

第二個案例是做一個用藥提醒 App。作者同樣先用計畫模式描述需求，讓 Codex 提出方案並自動實作。

當需要把 App 傳到手機時，Codex 會提示安裝 Xcode。作者提到可以透過 Computer Use 協助搜尋、下載、安裝與操作編譯流程；涉及密碼或登入等安全步驟時，仍需要使用者自己處理。手機端還需要資料線、開發者模式與信任確認等步驟。

作者也提到手機操作 Codex 的新功能，方便在手機上遠端繼續開發。

### 七、平台差異

文章最後提醒 Mac 與 Windows 功能差異。作者列出 Mac 目前支援但 Windows 尚未完整支援的能力，例如 Computer Use、遠端手機連接、Appshots、Locked Computer Use、Chronicle 與 Goal Mode。這些平台差異會影響使用者能採用的工作流。
